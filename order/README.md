# 🌶️ เว็บสั่งหม่าล่าหน้าแดง

เว็บสั่งอาหารสำหรับลูกค้า — หน้าเดียวจบ ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์
เปิดไฟล์ `index.html` ก็ใช้ได้เลย

รูปแบบหน้าเว็บทำตามเว็บสั่งอาหารของ [Lagombake](https://github.com/imsummerr/Lagombake)
แต่เปลี่ยนเป็นธีมแดง–ขาว–ดำ และใช้เมนู ราคา และตัวเลือกปรุงรสชุดเดียวกับ
POS ของร้าน ([`imsummerr/malanadaengstock`](https://github.com/imsummerr/malanadaengstock))

## มีอะไรบ้าง

| ส่วน | รายละเอียด |

| เลือกสาขา | ตลาดทรัพย์พัฒนา · แบริ่ง — สาขาไหนก็ได้ QR ของสาขานั้น |
| 🍲 หม่าล่าลวก | เลือก **น้ำซุป 9 แบบ · ความเผ็ด 5 ระดับ · น้ำจิ้ม 3 แบบ** แล้วเลือกวัตถุดิบ 39 อย่าง |
| 🔥 หม่าล่าย่าง | วัตถุดิบ 30 อย่างที่ย่างได้ + ความเผ็ดผงหม่าล่า + น้ำจิ้ม |
| 🍜 มาม่า | 5 ราคา (10 / 15 / 20 / 35 / 45 บาท) |
| ➕ ของเพิ่ม | สาหร่ายแผ่น 20 บาท |
| 🍱 เมนูจัดชุด | อุด้ง · หม่าล่าหน้าแดง · หม่าล่าทะเล · หม่าล่ารวม (ซ่อนไว้จนกว่าจะใส่ราคา) |
| 📍 ที่อยู่ | พิมพ์เอง / กดใช้ตำแหน่งปัจจุบัน / ปักหมุดบนแผนที่แล้วลากได้ |
| 💳 ชำระเงิน | QR พร้อมเพย์ที่**ใส่ยอดเงินมาให้แล้ว** + แนบสลิป |

ส่วนลดคิดแบบเดียวกับหน้าร้าน: **ครบทุก 10 ไม้ ลด 5 บาท**
(นับเฉพาะไม้ — มาม่า ของเพิ่ม และเมนูจัดชุด ไม่นับ)

## ⚠️ ต้องตรวจก่อนเปิดใช้จริง

**ราคาวัตถุดิบรายตัว** — POS เก็บราคาเป็น "ขั้น" (ไม้ละ 10 กับ 15 บาท)
ไม่ได้เก็บว่าของชิ้นไหนอยู่ขั้นไหน ราคาที่ใส่ไว้ในไฟล์นี้จึงเป็นการ**เดาตามประเภทของ**
ให้เทียบกับป้ายหน้าร้านแล้วแก้ที่ `const ITEMS` ใน `index.html` ก่อนเอาไปใช้จริง

## ตั้งค่า

แก้ได้ที่บล็อก `const CONFIG` ด้านบนของ `<script>` ก้อนสุดท้ายใน `index.html`

| ค่า | ค่าตั้งต้น | ทำอะไร |
|---|---|---|
| `lineOaId` | `''` | ไลน์ OA ของร้าน เช่น `'@malanadaeng'` — ใส่แล้วจะมีปุ่ม "ส่งเข้าไลน์ร้าน" |
| `orderApiUrl` | `''` | URL Apps Script ที่รับออเดอร์ — ใส่แล้วออเดอร์จะถูกยิงไปเก็บอัตโนมัติ |
| `imgbbKey` | `''` | API key ของ [ImgBB](https://api.imgbb.com/) สำหรับอัปโหลดสลิป |
| `deliveryFee` | `0` | ค่าส่ง (บาท) — `0` = คิดตามระยะทาง ไม่รวมใน QR |
| `requireSlip` | `true` | บังคับแนบสลิปก่อนส่งออเดอร์ |
| `banks` | `[]` | บัญชีธนาคารสำรอง |
| `mapCenter` | สมุทรปราการ | จุดกลางแผนที่ตอนยังไม่รู้ตำแหน่งลูกค้า |

**พร้อมเพย์แต่ละสาขา** อยู่ที่ `const BRANCHES` — ค่าเดียวกับ `DEFAULT_BRANCH_QR`
ใน `pos.html` ถ้าเปลี่ยนที่ POS ต้องมาเปลี่ยนที่นี่ด้วย
สาขาที่ `promptpayId` ว่าง ระบบจะซ่อน QR แล้วบอกลูกค้าให้โอนตามบัญชีแทน

**เมนูจัดชุด** อยู่ที่ `const SET_MENUS` ตั้งต้นราคาเป็น `0` ทุกอัน
หมวดนี้จะถูกซ่อนจนกว่าจะมีอย่างน้อย 1 รายการที่ใส่ราคาแล้ว

## ออเดอร์ไปไหน

1. ถ้าตั้ง `orderApiUrl` ไว้ → ยิง JSON ไปที่นั่น (`mode: 'no-cors'` แบบเดียวกับเว็บ Lagombake)
2. ไม่ว่าจะตั้งหรือไม่ → ลูกค้าจะเห็นข้อความสรุปออเดอร์ กด **คัดลอก** หรือ **ส่งเข้าไลน์ร้าน** ได้

ถ้าไม่ได้ตั้ง `imgbbKey` ระบบจะแนบสลิปไว้ในเครื่องลูกค้าอย่างเดียว
แล้วบอกให้ส่งรูปสลิปตามมาในแชท — ข้อความสรุปจะเขียนกำกับไว้ให้แล้ว

## ไฟล์ที่ใช้

```
order/
├── index.html                   ทั้งเว็บอยู่ในไฟล์นี้ไฟล์เดียว
├── vendor/jsqr.min.js           อ่าน QR ในสลิป (jsQR v1.4.0, Apache-2.0)
└── LICENSES/jsQR-Apache-2.0.txt
```

ตัวสร้าง QR (`QRCodeGen`) และตัวสร้าง payload พร้อมเพย์ (`PromptPay`)
ยกมาจาก `pos.html` ของระบบ POS ตรง ๆ เพื่อให้ QR ที่ลูกค้าสแกน
เป็นเลขพร้อมเพย์ชุดเดียวกับที่หน้าร้านใช้

ต้องต่อเน็ตแค่ 2 อย่าง และทั้งสองอย่างพังแล้วเว็บยังใช้ได้:

- **ฟอนต์ Sarabun** จาก Google Fonts — โหลดไม่ได้ก็ตกไปใช้ฟอนต์ระบบ
- **แผนที่ Leaflet + แผ่นแผนที่ OpenStreetMap** — โหลดไม่ได้ระบบจะซ่อนแผนที่
  แล้วบอกลูกค้าให้พิมพ์ที่อยู่แทน (ไม่ต้องใช้ API key และไม่เสียเงิน)
