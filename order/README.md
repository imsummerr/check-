# 🌶️ เว็บสั่งหม่าล่าหน้าแดง

เว็บสั่งอาหารสำหรับลูกค้า — หน้าเดียวจบ ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์
เปิดไฟล์ `index.html` ก็ใช้ได้เลย

เมนู ราคา และตัวเลือกปรุงรสใช้ชุดเดียวกับ POS ของร้าน
([`imsummerr/malanadaengstock`](https://github.com/imsummerr/malanadaengstock))
รูปแบบหน้าเว็บทำตาม [Lagombake](https://github.com/imsummerr/Lagombake) แต่เป็นธีมแดง–ขาว–ดำ

## ลำดับหน้าที่ลูกค้าเห็น

| # | ขั้นตอน | รายละเอียด |
|---|---|---|
| 1 | **เลือกวัตถุดิบ** | เปิดมาเจอลิสต์เลย 45 รายการ เรียงลงมาเป็นหมวด — เนื้อสัตว์ · ทะเล · เสียบไม้ · ผัก/เห็ด · เส้น/แป้ง · แปรรูป · มาม่า · ของเพิ่ม |
| 2 | **น้ำซุป / วิธีทำ** | 10 ตัวเลือก — 9 แบบจาก POS บวก **ย่าง** · แล้วเลือกระดับความเผ็ด 5 ระดับ |
| 3 | **น้ำจิ้ม** | น้ำจิ้มงา · น้ำจิ้มสุกี้ · ไม่เอาน้ำจิ้ม |
| 4 | **ชื่อ + เบอร์โทร** | ใช้ตอนไปส่ง |
| 5 | **ที่อยู่จัดส่ง** | พิมพ์เอง / ใช้ตำแหน่งปัจจุบัน / ปักหมุดเอง / ค้นหาจากที่อยู่ → **คิดค่าส่งจากระยะทางให้ทันที** |
| 6 | **สรุปออเดอร์** | รายการ + ส่วนลด + ค่าส่ง = ยอดที่ต้องโอน |
| 7 | **QR พร้อมเพย์** | ใส่ยอดเงินมาให้แล้ว สแกนโอนได้เลย |
| 8 | **แนบรูปสลิป** | แนบแล้วระบบอ่าน QR ในสลิปให้ร้านตรวจสอบ |

เลือก **"ย่าง"** ในช่องน้ำซุปได้เลย ไม่ต้องไปหมวดอื่น
ของที่ย่างไม่ได้ (ผักใบ เส้น แมงกะพรุน) จะขึ้นคำเตือนเล็ก ๆ ที่รายการนั้นว่าร้านจะลวกให้แทน

**ส่วนลด** ครบทุก 10 ไม้ ลด 5 บาท — นับเฉพาะไม้ มาม่า ของเพิ่ม และเมนูจัดชุดไม่นับ (ตาม POS)

## 🚚 ค่าส่งตามระยะทาง

วัดเส้นตรงจากพิกัดร้านถึงหมุดที่ลูกค้าปัก แล้วคิดตามนี้

```
ไม่เกิน 1 กม.  →  ส่งฟรี
เกิน 1 กม.    →  กิโลละ 10 บาท ปัดขึ้น
```

| ระยะทาง | ค่าส่ง |
|---|---|
| 1.00 กม. | ฟรี |
| 1.10 กม. | 10 ฿ |
| 2.00 กม. | 10 ฿ |
| 2.10 กม. | 20 ฿ |
| 5.70 กม. | 50 ฿ |

ค่าส่งรวมอยู่ในยอดของ QR พร้อมเพย์แล้ว
ถ้าลูกค้ายังไม่ปักหมุด ระบบจะไม่เดาค่าส่งให้ — จะขึ้นว่าทางร้านจะแจ้งทีหลัง

แก้กติกาได้ที่ `const DELIVERY = { freeKm: 1, bahtPerKm: 10 }`

## ⚠️ 2 อย่างที่ต้องทำก่อนเปิดใช้จริง

### 1. ตั้งพิกัดหน้าร้าน (ไม่ตั้ง = คิดค่าส่งไม่ได้)

`SHOP.lat` กับ `SHOP.lng` ตั้งต้นเป็น `null` เพราะเดาพิกัดร้านเองไม่ได้
ถ้าเดาผิดค่าส่งจะผิดทุกบิล ระบบเลยเลือกที่จะ**ไม่คิดค่าส่งเลย**จนกว่าจะตั้ง

วิธีตั้ง — ทำครั้งเดียว:

1. เปิด `index.html?setshop=1` (ต่อ `?setshop=1` ท้าย URL)
2. จิ้มตำแหน่งหน้าร้านบนแผนที่ ลากหมุดปรับให้ตรง
3. กด **คัดลอกไปวางในโค้ด** แล้วเอาไปแทนบรรทัด `lat:` กับ `lng:` ใน `const SHOP`

หน้านี้ลูกค้าไม่เห็น เพราะต้องพิมพ์ `?setshop=1` เอง

### 2. ตรวจราคาวัตถุดิบรายตัว

POS เก็บราคาเป็น "ขั้น" (ไม้ละ 10 กับ 15 บาท) ไม่ได้เก็บว่าของชิ้นไหนอยู่ขั้นไหน
ราคาที่ใส่ไว้จึงเป็นการ**เดาตามประเภทของ** — ให้เทียบกับป้ายหน้าร้าน
แล้วแก้ที่ `const ITEMS` ก่อนเอาไปใช้จริง

## ตั้งค่าอื่น ๆ

แก้ได้ที่บล็อกบนสุดของ `<script>` ก้อนสุดท้ายใน `index.html`

| ค่า | ค่าตั้งต้น | ทำอะไร |
|---|---|---|
| `SHOP.promptpayId` | เลขของตลาดทรัพย์พัฒนา | ชุดเดียวกับ `DEFAULT_BRANCH_QR` ใน `pos.html` |
| `CONFIG.lineOaId` | `''` | ไลน์ OA ของร้าน เช่น `'@malanadaeng'` — ใส่แล้วจะมีปุ่ม "ส่งเข้าไลน์ร้าน" |
| `CONFIG.orderApiUrl` | `''` | URL Apps Script ที่รับออเดอร์ — ใส่แล้วออเดอร์จะถูกยิงไปเก็บอัตโนมัติ |
| `CONFIG.imgbbKey` | `''` | API key ของ [ImgBB](https://api.imgbb.com/) สำหรับอัปโหลดสลิป |
| `CONFIG.requireSlip` | `true` | บังคับแนบสลิปก่อนส่งออเดอร์ |
| `CONFIG.banks` | `[]` | บัญชีธนาคารสำรอง |
| `SET_MENUS` | ราคา `0` | เมนูจัดชุด — ใส่ราคาแล้วจะขึ้นในลิสต์เอง |

## ออเดอร์ไปไหน

1. ถ้าตั้ง `orderApiUrl` ไว้ → ยิง JSON ไปที่นั่น (`mode: 'no-cors'` แบบเดียวกับเว็บ Lagombake)
2. ไม่ว่าจะตั้งหรือไม่ → ลูกค้าจะเห็นข้อความสรุปออเดอร์ กด **คัดลอก** หรือ **ส่งเข้าไลน์ร้าน** ได้

ถ้าไม่ได้ตั้ง `imgbbKey` ระบบจะแนบสลิปไว้ในเครื่องลูกค้าอย่างเดียว
แล้วบอกให้ส่งรูปสลิปตามมาในแชท — ข้อความสรุปจะเขียนกำกับไว้ให้แล้ว

## ไฟล์ที่ใช้

```
order/
├── index.html                   ทั้งเว็บอยู่ในไฟล์นี้ไฟล์เดียว
├── vendor/jsqr.min.js           อ่าน QR ในสลิป (jsQR v1.4.0, Apache-2.0)
└── LICENSES/jsQR-Apache-2.0.txt
```

ตัวสร้าง QR (`QRCodeGen`) และตัวสร้าง payload พร้อมเพย์ (`PromptPay`)
ยกมาจาก `pos.html` ของระบบ POS ตรง ๆ เพื่อให้ QR ที่ลูกค้าสแกน
เป็นเลขพร้อมเพย์ชุดเดียวกับที่หน้าร้านใช้

ต้องต่อเน็ตแค่ 3 อย่าง และทุกอย่างพังแล้วเว็บยังใช้ได้:

- **ฟอนต์ Sarabun** จาก Google Fonts — โหลดไม่ได้ก็ตกไปใช้ฟอนต์ระบบ
- **แผนที่ Leaflet + แผ่นแผนที่ OpenStreetMap** — โหลดไม่ได้ระบบจะซ่อนแผนที่
  แล้วบอกลูกค้าให้พิมพ์ที่อยู่แทน (ไม่ต้องใช้ API key และไม่เสียเงิน)
- **ค้นหาที่อยู่ Nominatim** (OpenStreetMap) — ใช้ตอนกดปุ่ม "ค้นหาจากที่อยู่" เท่านั้น
  ค้นไม่เจอก็ปักหมุดเองได้
