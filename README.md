# 🌶️ ระบบสต็อกครัวกลางหม่าล่า (Central Kitchen → สาขา + LINE)

ระบบบันทึกการเคลื่อนของสต็อกจาก **ครัวกลาง → แต่ละสาขา** พร้อม **แจ้งเตือน LINE**
และคำนวณ **ของหาย** อัตโนมัติ เก็บข้อมูลทั้งหมดใน **Google Sheet**

## รอบการทำงาน (FIFO log)
```
ครัวกลางกรอกของออก  ──▶  บันทึกลง Google Sheet + คำนวณ "ควรแพ็คได้กี่ถุง"
        │                        (จากน้ำหนัก ÷ กรัมต่อถุง เช่น สันคอ 30 ก./ถุง)
        ▼
แจ้งเตือนเข้ากลุ่ม LINE สาขา  ──▶  ข้อความมีปุ่มลิงก์ให้กรอก
        │
        ▼
พนักงานสาขากดลิงก์ → กรอก "แพ็คได้จริงกี่ถุง"
        │
        ▼
ระบบคำนวณ ของหาย = ควรได้ − แพ็คจริง  ──▶  บันทึกกลับ Sheet + อัปเดตหน้า "สรุป"
```

## สิ่งที่ได้
- 📝 **บันทึกง่าย** — ครัวกลางเลือกสาขา + สินค้า + น้ำหนัก แค่นั้น
- 🧮 **คำนวณควรแพ็คได้** — จาก "กรัมต่อถุง" ของแต่ละสินค้า (เช่น สันคอ 1 กก. → ~33 ถุง)
- 🔔 **แจ้ง LINE อัตโนมัติ** — เข้ากลุ่มของสาขานั้น ๆ พร้อมลิงก์กรอกงานแพ็ค
- 📦 **หน้าแพ็คสำหรับสาขา** — เปิดจากลิงก์ใน LINE กรอกจำนวนที่แพ็คได้ เห็นของหายทันที
- 📉 **คำนวณของหาย** — เทียบควรได้ vs แพ็คจริง (ถุง/กรัม) แยกตามสินค้าและสาขา
- 📊 **หน้าสรุป** — ยอดส่งออก / แพ็คได้ / ของหายรวม + ประวัติล่าสุด
- 🗂️ **ข้อมูลอยู่บน Google Sheet** — เปิดดู กรอง ทำรายงานต่อได้เอง

## โครงสร้างไฟล์
```
apps-script/
  Code.gs            # แบ็กเอนด์: เขียน Sheet, ส่ง LINE, คำนวณของหาย, webhook
  Style.html         # สไตล์กลาง (ใช้ร่วมทุกหน้า)
  Index.html         # หน้าแรก + สรุป + ประวัติ
  Entry.html         # หน้าครัวกลางกรอกของออก
  Pack.html          # หน้าสาขากรอกจำนวนที่แพ็คได้ (เปิดจากลิงก์ LINE)
  appsscript.json    # ตั้งค่าโปรเจกต์ (timezone, สิทธิ์)
SETUP.md             # 👉 คู่มือติดตั้งทีละขั้น (อ่านไฟล์นี้)
legacy-offline-app/  # เวอร์ชันเก่าแบบเก็บในเครื่องอย่างเดียว (ไม่ต่อ LINE/Sheet)
```

## เริ่มใช้งาน
อ่าน **[SETUP.md](SETUP.md)** — คู่มือติดตั้งทีละขั้นแบบละเอียด (สร้างชีต, วางโค้ด, Deploy, เชื่อม LINE)

## หมายเหตุ
- ใช้ **LINE Official Account (Messaging API)** — LINE Notify แบบเก่าถูกปิดไปแล้ว
- **Channel access token** เก็บใน Script Properties ของ Apps Script เท่านั้น **อย่า commit ลง repo**
