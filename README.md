# 🌶️ ระบบสต็อกครัวกลางหม่าล่า

ระบบบันทึกสต็อกครัวกลาง–สาขา พร้อมแจ้งเตือน LINE แยกกลุ่ม
เก็บข้อมูลทั้งหมดใน **Google Sheet** ทำงานบน **Google Apps Script** (ฟรี ไม่ต้องเช่าเซิร์ฟเวอร์)

## 5 เมนูหลัก

| เมนู | ทำอะไร | แจ้งเข้ากลุ่ม |
|---|---|---|
| 📥 **ของเข้าครัวกลาง** | เสียบ+แพ็คเสร็จแล้วลงยอด | กลุ่มครัวกลาง |
| 🏪 **ของเข้าร้าน** | ส่งของไปสาขา | กลุ่มสาขานั้น |
| 📋 **เช็คสต็อกรายสัปดาห์** | นับให้ครบทุกรายการ เทียบระบบ แล้วปรับยอดให้ตรง | กลุ่มของสถานที่นั้น |
| 🗑️ **ของเสีย** | ตัดออกจากสต็อก | กลุ่มของสถานที่นั้น |
| 💵 **สรุปยอดขาย** 🔒 | ยอด POS + ตรวจเช็คของหาย — **แอดมินเท่านั้น** | — |

พร้อมแจ้งเตือนอัตโนมัติ 2 อย่าง เข้ากลุ่ม LINE:
- ⏰ **วันหมดอายุ** — ทุกเช้า 8 โมง แจ้งเฉพาะของที่หมดอายุ *วันนี้* ครั้งเดียว ไม่แจ้งซ้ำ
- ⚠️ **ของครัวกลางใกล้หมด** — แจ้งทันทีที่ตกต่ำกว่าจุดเตือน (ครั้งเดียวจนกว่าจะเติมของ) + สรุปทุกเช้า

## หน่วยนับ 2 ระดับ

แต่ละสินค้าตั้งค่า **หน่วยย่อย** (ไม้ / กรัม / ชิ้น) และ **หน่วยแพ็ค** (แพ็ค / ถุง)

```
ลูกชิ้น 1 ถุง = 26 ชิ้น  →  เสียบได้ 26 ไม้  →  แพ็คละ 7 ไม้
                                    ↓
                    ลงสต็อก "3 แพ็ค 5 ไม้"   (ระบบเก็บจริงเป็น 26 ไม้)
                                    ↓
              ส่งเข้าร้าน 1 แพ็ค  →  ระบบรู้ว่า = 7 ไม้  →  ครัวกลางเหลือ 2 แพ็ค 5 ไม้
```

ระบบเก็บยอดเป็น **หน่วยย่อย** เสมอ แล้วแปลงกลับเป็นแพ็คตอนแสดงผล — บวกลบข้ามแพ็คได้ไม่เพี้ยน

## ตรวจเช็คของหาย — เทียบของกับเงิน

```
ขายได้(หน่วยย่อย) = นับต้นงวด + ของเข้า − ของเสีย − แถมฟรี − นับปลายงวด
ยอดที่ควรได้      = Σ(ขายได้ × ราคาต่อหน่วยย่อย) − ส่วนลด
ส่วนต่าง          = เงินเข้าจริง(POS) − ยอดที่ควรได้
                     ↑ ติดลบ = เงินขาด / ของหายโดยไม่มีเงินเข้า
```

- คิดเป็น **หน่วยย่อย (ไม้)** ไม่ใช่แพ็ค — เศษไม่ตกหล่น
- **ของแถม (น้ำจิ้ม)** หักที่ *จำนวนของ* ไม่ใช่เงิน → บันทึกที่เมนูของเสีย เลือกประเภท "แถมฟรี"
- **ส่วนลด** หักที่ *เงิน* → บันทึกที่เมนูยอด POS
- เลือกช่วงวันที่เองได้ ระบบหาการนับสต็อกที่ครอบช่วงนั้นให้ และบอกว่าใช้วันไหนเป็นต้น/ปลายงวด

## สิทธิ์ผู้ใช้

| บทบาท | ทำอะไรได้ |
|---|---|
| **แอดมิน** | ทุกอย่าง ทุกสถานที่ |
| **ครัวกลาง** | ของเข้าครัวกลาง, ของเข้าร้าน, เช็คสต็อก, ของเสีย |
| **สาขา** | เช็คสต็อก + ของเสีย **เฉพาะสาขาตัวเอง** (ไม่เห็นข้อมูลเงิน) |

รหัสผ่านเก็บเป็น hash (SHA-256 + salt) และตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง

## โครงสร้างไฟล์

```
apps-script/
  Code.gs         # แบ็กเอนด์ทั้งหมด (สต็อก, LINE, ล็อกอิน, ทริกเกอร์หมดอายุ)
  Style.html      # สไตล์กลาง
  Auth.html       # ฟอร์มล็อกอิน + session
  Common.html     # ฟังก์ชันร่วม (แปลงหน่วย, toast, dropdown)
  Index.html      # หน้าแรก: 4 เมนู + ใกล้หมดอายุ + สต็อกคงเหลือ
  StockIn.html    # ของเข้าครัวกลาง
  ToShop.html     # ของเข้าร้าน
  Count.html      # เช็คสต็อกรายสัปดาห์
  Waste.html      # ของเสีย
  Sales.html      # สรุปยอดขาย: ยอด POS + ตรวจของหาย (แอดมินเท่านั้น)
SETUP.md          # 👉 คู่มือติดตั้งทีละขั้น
```
