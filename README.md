# 🌶️ บันทึกเวลาเข้าสต็อก – ครัวกลางหม่าล่า

แอปเว็บสำหรับบันทึก **เวลาของเข้าสต็อก** ที่ครัวกลางหม่าล่าและแต่ละสาขา
ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์ ไม่ต้องติดตั้งเซิร์ฟเวอร์ เปิดไฟล์เดียวก็ใช้ได้เลย

## วิธีใช้
1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome / Safari / Edge)
2. บนมือถือ กด "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) เพื่อใช้เหมือนแอปจริง

## ความสามารถ
- ➕ **บันทึกรายการเข้าสต็อก**: เลือกสถานที่ (ครัวกลาง/สาขา), ชื่อวัตถุดิบ, หมวด, จำนวน+หน่วย,
  **วันเวลาที่เข้าสต็อก** (มีปุ่ม "ตอนนี้"), วันหมดอายุ, ผู้บันทึก และหมายเหตุ
- 🏬 **แยกตามสถานที่**: ครัวกลางเป็นหลัก และเพิ่มสาขาได้ไม่จำกัดในเมนู "จัดการสถานที่"
- 📋 **ตารางรายการ**: เรียงตามเวลาล่าสุด กรองตามสถานที่ และค้นหาได้
- 📊 **สรุป**: จำนวนทั้งหมด, เข้าวันนี้, ใกล้หมดอายุ (≤3 วัน), เกินอายุแล้ว
- ⏰ **เตือนวันหมดอายุ**: ไฮไลต์รายการที่ใกล้/เกินวันหมดอายุ
- ⬇️ **ส่งออก CSV**: เปิดต่อใน Excel / Google Sheets ได้ (รองรับภาษาไทย)

## การเก็บข้อมูล
ข้อมูลถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ๆ (offline, เป็นส่วนตัว)
แนะนำให้กด **ส่งออก CSV** สำรองข้อมูลเป็นระยะ

> อยากให้ทุกสาขาเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์? สามารถต่อยอดเชื่อมฐานข้อมูลกลาง
> (เช่น Firebase / Supabase / Google Sheets) เพิ่มเติมได้ในภายหลัง

## ไฟล์ในโปรเจกต์
- `index.html` — ตัวแอปทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว)
- `manifest.json` — ตั้งค่าให้ติดตั้งเป็น PWA บนมือถือได้
